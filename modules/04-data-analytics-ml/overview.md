## Module Overview

**Instructor:** Ana Trisovic, Research Scientist at the FutureTech Lab at MIT.  

Welcome to Foundations of Data Analytics and Machine Learning! In this module, we dive into the basics of data, analytics, and visualization — essential tools for understanding information and solving problems. We explore what data really is — not just numbers, but text, images, audio, and more — and learn how to organize data, follow its journey from collection to analysis, and share it effectively.

This module covers:
- Different types of data — categories, numbers, locations, and time — and how each affects analysis and visualization.  
- Creating charts that tell stories and choosing the right visuals for your data.  
- A solid introduction to statistics — mean, median, mode, and standard deviation — to understand data at a deeper level.  
- An introduction to **machine learning**, where computers find patterns and make predictions from data.  
- **Reproducibility and ethics** — because working with data means being responsible and transparent.  

Each lecture comes with a downloadable PDF slide deck that maps directly to the visual materials shown in the video. These files are designed as an alternative study aid for reviewing key text, math, and graphics.

---

## Learning Goals

By the end of this module, learners will be able to:
- Understand the principles and workflow of data-driven analysis.  
- Communicate insights effectively using appropriate visual and statistical tools.  
- Make informed decisions about methods for data cleaning, visualization, and modeling.  
- Recognize how data characteristics (categorical, spatial, numerical) influence analysis techniques.  
- Develop foundational intuition for machine learning and its applications.

## Lecture Roadmap

| # | Lecture | Focus |
|---|---------|-------|
| 1 | Introduction to Data Analytics and Machine Learning | Defining data, data types, variables, and the data lifecycle |
| 2 | Categorical and Time Series Data | Bar charts, pie charts, line charts, and temporal trends |
| 3 | Descriptive Statistics | Mean, median, mode, variance, histograms, box plots, scatter plots, and correlation |
| 4 | Spatial Data and Mapping | Map projections, choropleths, cartograms, and spatial metrics |
| 5 | Machine Learning Fundamentals | Supervised, unsupervised, and reinforcement learning; regression, classification, and clustering |
| 6 | Reproducibility and Data Management | Version control, documentation, data provenance, and ethical data sharing |
| 7 | Effective Data Visualization | Data-ink ratio, visual hierarchy, color scales, and design best practices |
