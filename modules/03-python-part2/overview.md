## Module Overview
Instructor: **Ana Bell**, Senior Lecturer at MIT.  

Welcome to Module 2: Python Coding, Part 2!  

In this module, you’ll explore how Python supports **data analysis and modeling**, from core programming tools to machine learning methods.  

Key points:
- Learn **dictionaries**, the flexible key–value structure for text analysis, expense tracking, and frequency visualization.  
- Work with **CSV files, NumPy, and Pandas** to process structured data, compute statistics, and generate synthetic datasets.  
- Practice **visualization**: line plots, scatter plots, bar charts, and histograms, with NumPy arrays as the numerical backbone.  
- Gain intuition for **type abstractions**: built‑in types, libraries, and user‑defined classes (like fractions or loans) to design modular, extensible programs.  
- Culminate in **machine learning**: decision trees and random forests, entropy and information gain, ensemble methods to mitigate overfitting, applied to real‑world datasets like the Titanic.  

By the end, you’ll understand how Python’s ecosystem — from dictionaries and abstractions to visualization and machine learning — forms a coherent toolkit for analyzing data, designing resilient programs, and building predictive models across domains like healthcare, business, and beyond.  

Each lecture comes with a downloadable PDF slide deck that maps directly to the visual materials shown in the video. These serve as study aids for reviewing text, math, and graphics.

## Learning Goals
By the end of this module, learners will be able to:

**Master Advanced Python Data Structures**
- Understand and use Python dictionaries.  
- Use dictionaries to store appropriate data.  

**Read, Store, and Visualize Data**
- Understand the CSV format and how it represents structured data.  
- Read and parse CSV files.  
- Convert CSV data into NumPy arrays and Pandas DataFrames.  
- Create and manipulate NumPy arrays for 1D and 2D datasets.  
- Create various plot types using `matplotlib.pyplot`.  
- Learn how visualization complements statistical analysis to reveal trends in data.  

**Gain Intuition for Abstracting Data**
- Understand type abstraction and why it matters in Python programming.  
- Create user‑defined types with classes, attributes, and methods.  
- Build modular code using classes to simulate real‑world systems.  
- Design simulations of real‑life situations using data abstraction and object‑oriented design.  

**Write Code to do Machine Learning**
- Learn different types of ML problems: classification, regression, and clustering.  
- Study how decision trees and random forests work.  
- Understand overfitting and randomness in ensemble methods.  
- Apply learned Python skills to explore machine learning examples.
