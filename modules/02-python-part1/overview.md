## Module Overview
Instructor: **Ana Bell**, Senior Lecturer at MIT.  

This module is designed for beginners with no prior coding experience. It takes a future‑focused approach by teaching not only how to write code, but also how to understand what’s happening “under the hood.” Learners build a mental model of how machines think, which helps in debugging, reasoning, and collaborating with AI‑generated code.  

Key points:
- Programming is taught as both **reading and writing code**.  
- Learners practice spotting errors and debugging, mirroring real‑world scenarios.  
- The course emphasizes intuition for how computers execute instructions step by step.  
- AI assistants and collaboration are acknowledged as part of modern programming practice.  

---

## Learning Goals
By the end of this module, learners will be able to:
- See and write code in the Python programming language.  
- Build a mental model of what happens when code runs.  
- Gain intuition for how machines “think.”  
- Read already‑written code (including AI‑generated code) and understand it at a high level.  
- Spot errors and debug buggy code effectively.  

Each lecture comes with a downloadable PDF slide deck that maps directly to the visual materials shown in the video. These serve as study aids for reviewing text, math, and graphics.  

---

## Lecture Roadmap
- **Lecture 1**: What Computers Do For You — foundations of programs, expressions, assignments, functions.  
- **Lecture 2**: Logic and Decisions — making decisions in code, working with text.  
- **Lecture 3**: Repeating Actions — loops and repetition.  
- **Lecture 4**: Working with Data — handling lists and building towards useful programs.  
- **Lecture 5**: Putting Together Larger Programs — combining smaller building blocks into larger programs.
